CustomVina 接口参考 ​

本页按类型列出当前语言的图元、属性、表达式、状态和面板控件。每张表左侧为可填写的名称，右侧说明用途；数值范围来自当前绘制与布局校验。另见宿主输入、内部动作、绘制阶段和内置文案。

文件结构与值类型 ​

声明位置用途
Preset { dependsOn: "名称" }单层依赖声明；只能有一个独立基础，不带扩展名和路径
组件名 { ... }顶层组件，名称自定义；同层不允许重复
组件的 label、description、icon设置面板中该组件分组的标题、说明和图标
ui { ... }声明可保存的面板参数
vars { ... }声明可引用的表达式，适合尺寸、颜色等派生值
state { ... }声明每个收纳盒独立的会话状态
view { ... }声明视图树；子块默认是子视图，专用元数据块除外
Panel { ... }个性化设置面板的专用布局组件，见本页末尾
值类型示例与含义
数值12、-4.5，必须有限；尺寸默认 DIP，时间默认秒
毫秒160ms 等于数值 0.16
布尔true、false
字符串"Segoe UI"；支持 \n、\r、\t、\uXXXX、\"、\\ 转义
标识符pogget.action.view.toggle、pogget.label.titleClassic，作为文本 ID 使用
引用${vars.radius}、${pogget.width}，取其他属性或宿主输入的值
颜色rgb(30, 144, 255) 或 0..16777215 的 COLORREF 整数；不是 CSS 颜色字符串

图元类型 type ​

type用途与默认行为
group组织子视图；坐标、不透明度、可见性、启用状态和裁剪影响子节点，默认不画背景
rect矩形/圆角矩形，默认绘制填充，可加边框和阴影
rectanglerect 的别名
button与 rect 相同的绘制类型；通过 action、holdAction 或 toggle 接入交互
containerrect 的别名，不会额外创建一个 Pogget 收纳盒
solid实色方角矩形；保留方角，不使用 radius 绘制圆角
text绘制 label 提供的文字
icon绘制字体图标字符，使用 icon 与对应 font
image绘制 WIC 图片、Shell 图标或本次绘制的命名位图
glass玻璃高光/光效层，background 参与亮度计算，不自动填充背景
content绘制宿主登记的命名内容资源，如 Markdown；只在当前绘制调用中使用

建议始终显式填写 type。省略时，有子视图的节点默认为 group，没有子视图的节点默认为 text。旧的 type: "texture" 已移除，应保留原图元并使用 texture 属性。

pogget.native.Header 是布局兼容接口。pogget.native.Background、pogget.native.Tag、pogget.native.VinaIcon、pogget.native.Behavior 是保留的旧组件标识，走兼容路径，不是通用绘图类型；新组件使用上表图元和对应 slot。

布局与可见性 ​

属性类型、默认值与用途
x、y数值，默认 0，范围 ±32768；相对父视图的坐标
width、height数值，默认 40，范围 0..32768；视图尺寸，不会自动撑满父节点
w、h宽、高的兼容别名；同时存在时 width、height 优先
z数值，默认 0，范围 ±32768；同级绘制层级，相同值按声明顺序排列
visible布尔，默认 true；隐藏后不绘制、不命中，影响子视图
enabled布尔，默认 true；控制交互是否启用，影响子视图
opacity数值，默认 1，范围 0..1；整体不透明度，与父节点不透明度相乘
slot字符串；指定宿主绘制阶段，子节点默认继承，见完整表
interaction字符串；标记宿主交互范围，title 跟随标题状态，icon 用于文件图标范围；不产生重复绘制
roleinteraction 的兼容别名，显式 interaction 优先

裁剪 ​

属性类型、默认值与用途
clip布尔，默认 false；按当前视图矩形裁剪自身及后代，并限制命中
clipRadius数值，默认 0，范围 0..32768；裁剪圆角半径，需要启用 clip
clipLayer布尔，默认 false；使用共享蒙版合成层；正圆角也会启用该方式
clipAntialias"perPrimitive"（默认）或 "aliased"；裁剪抗锯齿方式

背景、纹理与边框 ​

属性类型、默认值与用途
background颜色，默认主题 midnight；指定填充颜色；非矩形图元需显式声明才有背景，glass 除外
fillOpacity数值，默认 1，范围 0..1；填充不透明度；普通玻璃也读取此参数
radius数值，默认 0，范围 0..32768；矩形、玻璃及受支持位图的圆角
cornerRadiusradius 的兼容别名，显式 radius 优先
texture布尔或 0..64；省略/false 为普通填充，true/数值 0 启用立体纹理，数值同时指定纹理描边宽度
border数值，默认 0，范围 0..64；独立边框宽度
borderColor颜色，默认主题 white；边框颜色
borderOpacity数值，默认 1，范围 0..1；边框不透明度；光效也用它控制基础边缘
borderStyle"solid"（默认）或 "dash"；实线或虚线边框
borderOnly布尔，默认 false；只画边框，跳过背景与纹理填充
blur数值，默认 0，范围 0..64；使用现有材质后端绘制背景模糊
blurRenderer"title"（默认）或 "snapshot"；分别选择标题材质和快照模糊后端；快照采样原点须非负

rect、rectangle、button、container、solid 可直接使用 texture。group、text、icon、image、content 还需显式 background。纹理不替代独立边框，仍可搭配虚线；glass 没有背景填充，不能靠 texture 生成实体表面。

属性默认值、范围与用途

点击、悬停与动画 ​

属性或块默认值、范围与用途
action短按执行的内部动作 ID，见完整动作表
holdAction达到长按阈值后，有效释放时执行的动作 ID
holdDelay0.4 秒，0..10；长按判定阈值
hitPaddingX、hitPaddingY0，0..256；点击区域在横纵方向向外扩展的距离
toggle字符串字面量，如 "state.expanded"；短按翻转已声明的布尔状态，再执行可选 action
hover { ... }悬停目标属性；支持的数值与颜色由现有悬停进度插值
transition0.2 秒，0..10；进入悬停时长
unhoverTransition默认跟随 transition，0..10；离开悬停时长
pressDuration0.15 秒，0..10；原生按钮按压动画时长
releaseDuration0.3 秒，0..10；原生按钮释放动画时长
pressScale0.85，0..8；原生按钮按压目标缩放
holdDuration0.3 秒，0..10；原生按钮长按反馈动画时长
holdScale0.9，0..8；原生按钮长按目标缩放
holdOffset5，±256；原生按钮长按反馈位移

通用节点的 hover 使用悬停动画器；press*、hold* 反馈参数由接入对应能力的原生按钮读取，不会自动给所有矩形增加按压形变。可通过下列只读悬停输入自行计算几何：

引用用途
${self.hovered}当前视图是否处于悬停目标状态，布尔值
${self.hoverProgress}当前悬停动画进度，0..1
${parent.hovered}、${parent.hoverProgress}父视图的相同输入
${组件.view.节点.hovered}、${组件.view.节点.hoverProgress}按完整视图路径读取悬停状态

自定义悬停区域 hoverRegion ​

在视图下添加 hoverRegion { ... } 可区分进入区域与保持区域。这里使用世界 DIP 坐标，不是相对父节点坐标。

字段用途
x、y、width、height指针进入悬停的矩形；省略字段使用当前视图矩形；宽高非负
retainX、retainY、retainWidth、retainHeight悬停后保持状态的矩形；省略字段跟随进入矩形，适合展开后扩大保持范围
enabled是否启用该区域；视图隐藏、禁用或指针离开会取消悬停

本地状态 state ​

text
Preset { dependsOn: "Pogget_Std" }

ExpandableCard {
  state { expanded: false, count: 0, caption: "详情" },
  view {
    type: "button", x: 16, y: 64,
    width: ${state.expanded} ? 240 : 100,
    height: 40,
    label: ${state.caption}, textLiteral: true,
    toggle: "state.expanded"
  }
}

状态默认值只接受布尔、有限数值或字符串字面量，可用负数。toggle 只翻转布尔变量；长按执行 holdAction 时不翻转。状态按收纳盒隔离，同一预设兼容热更新时保留，重启或切换预设时重置。要持久保存真实视图/折叠设置，应使用内部动作；要保存面板参数，使用 ui。

表达式与函数 ​

写法用途
+、-、*、/、%、^加、减、乘、除、浮点余数、幂；除数不能为零
==、!=、<、<=、>、>=比较，返回布尔值
&&、||、!逻辑与、或、非
条件 ? 值一 : 值二条件选择；表达式采用栈式求值，不要依赖分支短路来避开除零等错误
pi圆周率常量
min(a,b)、max(a,b)两个值的较小/较大值
clamp(v,lo,hi)将数值限制在闭区间内，要求 lo <= hi
abs(v)绝对值
floor(v)、ceil(v)向下/向上取整
round(v)四舍五入到整数，半值按 C++ round 规则远离零
trunc(v)向零截断，如 trunc(-1.8) = -1
f32(v)转为单精度再返回数值，用于保留原生浮点布局的舍入
sqrt(v)平方根，输入须非负
pow(a,b)幂，与 a ^ b 相同
hypot(x,y)计算 sqrt(x*x + y*y)
rgb(r,g,b)构造 COLORREF，各通道截断并限制到 0..255
red(c)、green(c)、blue(c)读取 COLORREF 的红、绿、蓝通道
average(c)读取颜色通道的整数平均亮度
fade(c,amount)兼容原生亮度调整：平均亮度大于 128 时减去 amount，否则加上；调整量先向零截断，范围 ±255，各通道限制到 0..255

fade() 不是不透明度函数，也不是始终变亮/变暗。字符串、布尔与数值的最终使用必须符合目标属性类型。没有循环、脚本和任意函数调用。

引用形式查找范围
${self.width}当前块的属性；兼容形式 ${self.width.value} 也可用
${parent.width}父块属性
${vars.name}当前组件的派生变量
${ui.Name.value}当前组件的面板参数值
${state.name}当前组件的会话状态
${Component.vars.name}其他组件的完整属性路径
${pogget.width} 等宿主只读输入，见完整输入表

设置控件 ui ​

每个 ui 子块声明一个控件，显式写 type 和 control。除按钮外提供 default，数值滑块同时填写 min、max、step。choice 的默认值是从 0 开始的选项序号。

controltype 与用途
slidernumber；数值滑块
numbernumber；当前映射到同一数值滑块
switchboolean；开关，默认值须为布尔
toggleswitch 的别名
choice通常为 number；通过 choices 或 options 声明下拉选项
selectchoice 的别名
textstring；文本编辑控件
edittext 的别名
colornumber；颜色编辑器，值为 COLORREF
button动作按钮，通过 action 调用内部动作，无需 default
fontstring；字体选择，保存字体族名称

控件字段 ​

字段用途
label控件标题，可用内置文案 ID
type值类型，常用 number、boolean、string
control上表控件名称
default初始值，必须与控件类型匹配
min、max、step数值下限、上限、步进，步进须大于零
bind原生设置绑定名，见下表；省略则保存该预设自己的参数
value运行时当前值，通常用 ${ui.字段名.value} 读取，不用它代替 default
visible是否在面板显示，可使用表达式
choices、options选项块，按声明顺序编号，可使用 c0: 文案，也可用含 label 的子块
invert对二选一选项的显示索引和值进行 1 - value 转换，常见于布尔设置
actionbutton 调用的内部动作
offsetY数值滑块的垂直绘制偏移
notice控件下方提示文案
noticeHeight、noticeGap提示高度、提示之后的布局增量，默认 50、58
effectiveDefault原生默认值哨兵的有效回退，例如 TitleBlurRadius 的 -1；应按标准控件使用
display数值滑块设为 "percent" 时，将标题中的数值显示为百分比

原生设置绑定 bind ​

以下 39 个绑定来自当前标准预设的完整控件集合，大小写需一致。原生设置与通用视图属性是不同层次，例如 cornerRad 是窗口设置，radius 是某个图元的圆角。

bind类型/值与用途
CompatibleLayer0..4；默认、静态、模糊、透明、扩展渲染层
BackgroundColorCOLORREF；收纳盒背景色
bgAlpha0..1；收纳盒背景不透明度
DwmCornerPreference0 小圆角、1 普通圆角；DWM 圆角偏好
cornerRad标准控件 0..20；窗口自定义圆角
EnableStaticMaterialLayerForD3D11布尔；启用 D3D11 静态材质层
shadowBlur标准控件 0..32；扩展窗口阴影模糊
shadowAlpha0..1；窗口阴影不透明度
