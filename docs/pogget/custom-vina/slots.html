目录

绘制阶段与高级布局 ​

type 选择图元，slot 选择宿主何时绘制该视图。修改原有标题、文件项目或编辑器时，先找到标准预设的对应组件，保留必要的阶段和元数据，再覆盖目标属性。

一个 slot 不是一套固定外观。它的子节点仍使用通用图元和属性，布局与颜色可以自行声明。以下列出当前标准场景的全部 45 个 slot。

标题与窗口 ​

slot用途
containerFrame整盒收尾阶段，绘制最终边框、玻璃/光效和标签着色；客户区像素尺寸通过 scale 换算
titleSurface标题表面、背景、边框、阴影、分隔线
titleCollapse折叠按钮的绘制、几何与动作
titleMore更多菜单按钮
titlePin悬停展开后的固定按钮
titlePinBackground固定按钮胶囊的背景
titlePinHotzone固定按钮胶囊的悬停区域，使用通用 hoverRegion
titleTag标题标签表面与文字
titleTab合并收纳盒的每个标签页，逐项提交 pogget.tab.*
titleSearchSurface标题搜索框的外部表面
titleSearchInput搜索输入框皮肤，editor 元数据同步文字测量与输入命中
titleSearchOptions搜索选项按钮
inlineSearchSurface内联搜索界面与返回/取消的表面、占位布局
inlineSearchBack内联搜索返回按钮
inlineSearchCancel内联搜索取消按钮

文件项目 ​

slot用途
fileIconSurface每个文件项目的背景、选中与悬停表面
fileIconContentShell 图标、文件夹条目预览、媒体缩略图与拖入提示
fileIconText文件名布局策略的根阶段，提供 textLayout 和 gridLayout
fileIconTitle列表等普通标题阶段
fileIconDetail列表大小、日期等详情文字阶段
fileGridTitle普通网格和媒体文件名
fileSearchHighlight每个搜索命中片段的高亮背景
fileSearchTitle使用原生命中文本布局绘制搜索文件名
filePreview文本/Markdown 预览卡片、正文、页脚与标题
fileIconMotion整个图标/拖动虚影的运动与动画策略，不是可见的背景层
fileGhostSurface列表拖动虚影的额外底板，也接入声明式虚影绘制

例如只修改标准文件项目表面的某个子节点，仍需在 FileIconSurface.view 的既有路径下覆盖。新增无 slot 的组件不会自动按文件数量重复；不要在普通组件里读取最后一次提交的 fileIcon.* 来模拟重复列表。

内联内容与工具栏 ​

slot用途
inlineContentSurface内联文件夹/编辑器遮罩、背景与布局元数据
inlineContentSnapshot退出/切换快照的裁切、缩放、不透明度与模糊
inlineNavigationSurface内联导航和编辑工具栏的整体表面与显隐策略
inlineNavigationBack后退按钮
inlineNavigationHome退出内联文件夹、回主页的按钮
inlineNavigationSave内联编辑保存按钮
inlineNavigationOpen用外部程序打开当前编辑文件的按钮
inlineNavigationSearch内联搜索开关按钮

Markdown 编辑器与分页 ​

slot用途
markdownEditorSurface多行编辑器背景与边框
markdownEditorPlaceholder占位文字
markdownEditorSelection根据真实字形矩形绘制选区片段
markdownEditorContent同步正文内容资源
markdownEditorCaret光标
markdownEditorScrollbars双轴滚动条
markdownEditorZoomHint缩放提示
markdownEditorViewport可选共享视口，统一选区、正文和光标的裁剪、原点与缩放
pageIndicatorSurface分页指示器根阶段与重复点数策略
pageIndicatorDot每个普通分页点
pageIndicatorActive活动分页标记

完整接管与回退 ​

功能接管要求与边界
内联导航inlineNavigationSurface 加 Back、Home、Save、Open、Search 五个按钮 slot 全部存在；不完整时使用整套原生工具栏
内联内容inlineContentSurface 与 inlineContentSnapshot 配合，旧/不完整声明保留原生背景和快照路径
Markdown 皮肤Surface、Placeholder、Selection、Content、Caret、Scrollbars、ZoomHint 七阶段完整；缺少时保留整套原生皮肤
Markdown 共享视口可选 markdownEditorViewport 组中必须有唯一的同名 content 资源；使用原生 zoom 作为独立输入
分页指示器Surface、Dot、Active 三阶段与 repeat.count 完整；不完整时使用原生指示器
文件文字与预览对应根 slot 和测量策略共同决定接入；缺少时保留对应原生阶段
整盒收尾缺少 containerFrame 时保留原生绘制；已声明但隐藏时主动隐藏该阶段；非法帧会请求原生回退

原生仍负责文件资源、拖放排序、编辑、IME、撤销、动画触发和生命周期。Markdown 语义内的表格、代码、图片等样式仍由原生处理。

动画与布局元数据 ​

以下块是宿主读取的布局/动画策略，不会生成额外绘制或点击节点。同名字段在不同块下含义不同，必须放在表中指定的路径。 依赖模式可只覆盖需要修改的项；从零声明时，应参照标准预设保留完整策略。

标题组件的 motion ​

位置是组件下的 motion，例如 TitleSurface.motion，不在 view 中。

字段用途与范围
enabled是否使用声明式折叠进度目标
targetProgress折叠进度目标，由宿主限制到 0..1
duration折叠时长，0..10 秒，默认 0.4
transitionDuration、searchDuration标题样式切换、搜索展开时长，0..10 秒，默认均为 0.4
searchFrom、searchTo搜索展开起止值，±256，默认 -4、0
targetX、targetY目标位置，±32768
targetWidth、targetHeight、targetRadius目标宽、高、圆角，0..32768
targetShadowY目标阴影纵偏移，±256
targetShadowAlpha、targetBorderAlpha目标阴影、边框不透明度，0..1

titleTab 的 view.motion ​

字段用途与范围
x、y、width、height当前标签目标矩形；坐标 ±32768，尺寸 0..32768
islandX、islandY、islandWidth、islandHeight标签背景岛矩形，范围同上

nextX下一个成员的横向布局游标，±32768
stripX、stripWidth标签条起点和宽度，分别为 ±32768、0..32768
weight当前成员布局权重，0..32768；宿主累计权重供分配宽度
contentReserve、titleExtension内容区、标题的附加占位，0..32768
minimumHeight、collapsedGap显示门槛高度与折叠间距，0..32768
hoverDuration、unhoverDuration悬停进入/离开时长，0..10 秒
selectionDuration、deselectionDuration选中/取消选中时长，0..10 秒
layoutDuration布局过渡时长，0..10 秒

titleSearchInput 的 editor ​

字段用途与范围
padding文字测量与命中的内边距，0..32768
textSize测量字号，1..256
font非空字体族，最多 256 个字符
caretDuration光标动画周期参数，0.001..10 秒

文字的绘制字号和布局测量应保持一致，避免点击位置、选区和 IME 坐标错位。

inlineSearchSurface 的 motion ​

字段用途与范围

backButtonX、cancelButtonX、buttonY返回、取消按钮坐标，±32768
searchX、searchY、searchWidth搜索框位置与宽度，坐标 ±32768、宽度 0..32768

usesSecondRow布尔；窄窗口是否使用第二行布局

这是 Markdown 多行编辑器的几何策略，与搜索框的 editor 不同。全部字段及非空 font 需要完整提供。

字段用途与范围

contentWidth、contentHeight内容可用宽高，1..32768
baseHeight不扣除横向滚动条时的基础高度，1..32768

font、textSize测量字体族和字号，字号 1..256，字体最多 256 字符
verticalTrack、verticalThumb纵向滚动条轨道、滑块长度，0..32768，滑块不大于轨道
horizontalTrack、horizontalThumb横向滚动条轨道、滑块长度，范围同上

pageIndicatorSurface 的 repeat ​

字段用途与范围
countrepeat { count: ... } 声明实际绘制的普通点数量，整数 0..256；可与真实页数不同

宿主只按此数量提交 pageIndicatorDot，将序号放入 pogget.pageIndicator.index，最后绘制 Active。点数上限、间距、边缘缩小和活动标记几何均由预设计算。

命名资源 ​

资源仅在对应同步绘制中可用，缺少时不画。资源名不是文件路径，也不是允许调用的函数名。

资源名配套类型与用途
thumbnailimage + imageRenderer: "resource"；当前文件缩略图/媒体封面
fileTitletext + textRenderer: "resource"；搜索命中的原生文件名布局
markdowncontent；当前文件的 Markdown 预览正文
inlineExit、inlineSwitchimage + imageRenderer: "resource"；内联退出、层级切换快照
markdownEditorcontent；当前多行编辑器正文
markdownEditorViewportcontent；调度编辑器共享视口内的选区、正文和光标；同名 slot 内只能声明一个

Header 兼容布局 ​

pogget.native.Header 只调整已有标题控件的位置，保留原生点击、长按和菜单。一个预设最多声明一个 Header。

text
Preset { dependsOn: "Pogget_Std" }

HeaderLayout {
  vars {
    tagWidth: ${pogget.titleTextWidth} + 58,
    tagLeft: (${pogget.width} - ${vars.tagWidth}) / 2
  },
  view {
    type: "pogget.native.Header",
    tagX: ${vars.tagLeft}, tagY: 6,
    tagWidth: ${vars.tagWidth}, tagHeight: 28,
    moreX: ${vars.tagLeft} + ${vars.tagWidth} - 22,
    moreY: 18
  }
}
字段用途
tagAlign"left" 或 "center"；标题标签的兼容对齐方式
tagX、tagY标签横纵位置，±32768
tagWidth、tagHeight标签尺寸，0..32768
moreX、moreY更多按钮位置，±32768
collapseX、collapseY折叠按钮位置，±32768

旧布局映射字段 ​

标准视图节点上的下列元数据把 Header 的字段映射到普通视图。通常保留标准声明，只覆盖 Header；新布局可以直接修改普通节点。

字段用途
legacyX、legacyY、legacyWidth、legacyHeight指定 Header 中用于覆盖节点相应几何的字段名
legacyOriginX、legacyOriginY、legacyOriginWidth、legacyOriginHeight对兼容覆盖值增加的原点/尺寸补偿
legacyExtraWidth宽度覆盖的额外补偿
legacyAlignX指定 Header 横向对齐字段；值为 center 时参与居中计算
legacyCenterWidth未从 Header 指定宽度时的居中宽度

映射先整体校验再发布，移除 Header 覆盖会恢复普通视图声明。本页根据当前 VinaView.hpp、VinaMarkdownGeometry.hpp、运行时接入点和 Pogget_Std.vina 核对（2026-11-08）。
