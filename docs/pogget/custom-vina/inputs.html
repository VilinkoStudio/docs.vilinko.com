宿主输入 ​

宿主输入由 Pogget 提供，在表达式中用 ${完整路径} 读取，例如 ${pogget.width}。以下按用途列出当前可用输入，均为只读事实；不能通过在预设里写同名属性来修改真实业务状态。

表中的“数值”默认单位为 DIP，“颜色”是 COLORREF。进度按对应原生动画器提交，不应一律假定为 0..1；自定义视图的 self.hoverProgress 才明确为 0..1。

收纳盒与主题 ​

输入类型与用途
pogget.width、pogget.height数值；收纳盒当前宽高
pogget.title文本；收纳盒标题
pogget.isListView布尔；是否为列表视图
pogget.locked布尔；布局是否锁定，不表示位置也锁定
pogget.collapsed布尔；普通折叠状态；悬停折叠需结合下表状态判断
pogget.upward布尔；是否向上展开
pogget.cornerRadius数值；收纳盒配置的圆角
pogget.nativeCornerRadius数值；原生窗口实际自定义圆角
pogget.mode数值；兼容/渲染层，0..4 对应默认、静态、模糊、透明、扩展
pogget.frame数值；透明边框模式，0..3 对应无、画布、原生、高光
pogget.staticMaterial布尔；是否启用 D3D11 静态材质层
pogget.layoutHidden布尔；当前原生布局隐藏策略的结果，用于标题与内容占位
pogget.shadowPadding布尔；窗口是否启用阴影留白
pogget.theme.darknight颜色；当前主题的深层背景色
pogget.theme.midnight颜色；当前主题的普通表面色
pogget.theme.midnightplus颜色；当前主题的次级表面色
pogget.theme.white颜色；当前主题的前景色，会随主题变化，不一定是纯白
pogget.theme.darken颜色；当前主题的暗部色
pogget.theme.accent颜色；当前主题强调色
pogget.theme.monochrome布尔；当前主题的背景红绿通道相等这一原生判定结果

标题与折叠 ​

输入类型与用途
pogget.titleY、pogget.titleHeight数值；当前标题纵坐标与高度
pogget.collapsedHeight数值；原生折叠高度
pogget.titleTextWidth数值；标题文字测量宽度
pogget.titleHidden布尔；标题当前是否隐藏
pogget.titleExtension数值；标题附加占位高度
pogget.titleVariant数值；当前标题样式分支
pogget.titleProgress数值；标题折叠动画进度
pogget.titleTransitioning布尔；标题是否正在切换样式
pogget.titleOffsetAnim数值；标题显示/隐藏的动画偏移
pogget.searching布尔；标题当前搜索状态
pogget.searchExpand数值；标题搜索展开动画值
pogget.titleColor颜色；当前标题表面的有效颜色
pogget.titleBorderColor颜色；当前标题边框色
pogget.titleCustomColor布尔；标题是否使用主题色以外的来源，包括标签色和自定义色
pogget.buttonColor颜色；标题按钮的有效前景色
pogget.hoverCollapsed布尔；是否处于悬停展开式折叠模式
pogget.hoverExpanded布尔；悬停折叠的收纳盒当前是否展开
pogget.hoverExpandingAnimation布尔；是否正在进行悬停展开动画
pogget.temporaryTopmost布尔；是否处于临时置顶会话
pogget.pinProgress数值；固定按钮胶囊的动画进度
pogget.titleFluidX、pogget.titleFluidY数值；标题过渡动画当前表面的起点
pogget.titleFluidWidth、pogget.titleFluidHeight数值；标题过渡动画当前表面的宽高
pogget.titleFluidRadius数值；标题过渡动画当前圆角
pogget.titleFluidShadowY数值；标题过渡动画当前阴影纵偏移
pogget.titleFluidShadowAlpha数值；标题过渡动画当前阴影不透明度
pogget.titleFluidBorderAlpha数值；标题过渡动画当前边框不透明度

原生按钮反馈 ​

以下四组完整路径均可读取。hover 是原生按钮反馈值；pressScale、holdScale 是缩放，holdY 是长按位移，opacity 是按钮不透明度。

输入组用途
pogget.titleCollapse.hover、pogget.titleCollapse.pressScale、pogget.titleCollapse.holdScale、pogget.titleCollapse.holdY、pogget.titleCollapse.opacity折叠按钮反馈
pogget.titleMore.hover、pogget.titleMore.pressScale、pogget.titleMore.holdScale、pogget.titleMore.holdY、pogget.titleMore.opacity更多按钮反馈
pogget.titlePin.hover、pogget.titlePin.pressScale、pogget.titlePin.holdScale、pogget.titlePin.holdY、pogget.titlePin.opacity固定按钮反馈
pogget.titleSearchOptions.hover、pogget.titleSearchOptions.pressScale、pogget.titleSearchOptions.holdScale、pogget.titleSearchOptions.holdY、pogget.titleSearchOptions.opacity搜索选项按钮反馈

pogget.tag.hover、pogget.tag.push数值；原生标签悬停、按压进度

pogget.tab.accent、pogget.tab.textColor颜色；当前成员强调色与文字色
pogget.tab.text文本；当前标签标题
pogget.tab.displayUnits数值；当前标签的 Unicode 显示单位数
pogget.tab.x、pogget.tab.y数值；当前标签绘制位置
pogget.tab.width、pogget.tab.height数值；当前标签绘制尺寸
pogget.tab.hover、pogget.tab.selection数值；悬停与选中动画进度
pogget.tab.pressed、pogget.tab.dragging布尔；是否按下、是否拖动

pogget.editor.scroll数值；水平滚动偏移

文件项目 pogget.fileIcon ​

这些输入在文件图标、文字、预览或拖动虚影的相应阶段逐项更新。普通无 slot 组件不会自动为所有文件重复绘制；应配合文件项目绘制阶段使用。

几何与状态 ​

输入类型与用途
pogget.fileIcon.x、pogget.fileIcon.y数值；原生文件项目位置
pogget.fileIcon.drawX、pogget.fileIcon.drawY数值；当前绘制位置
pogget.fileIcon.size、pogget.fileIcon.height数值；图标尺寸与项目高度
pogget.fileIcon.viewportWidth数值；当前文件视口宽度
pogget.fileIcon.padding、pogget.fileIcon.spacing数值；项目内边距与排列间距
pogget.fileIcon.customWidth数值；自定义宽度，负值表示未指定
pogget.fileIcon.textSize数值；当前文件名字号
pogget.fileIcon.wrapOverflow数值；提前测量得到的文字换行溢出量
pogget.fileIcon.clipLeft、pogget.fileIcon.clipTop、pogget.fileIcon.clipRight、pogget.fileIcon.clipBottom数值；原生交互单元裁切边界
pogget.fileIcon.list布尔；当前项目按列表绘制
pogget.fileIcon.textPreview布尔；当前使用文本预览
pogget.fileIcon.wrap布尔；项目换行状态
pogget.fileIcon.clip布尔；是否需要单元裁切
pogget.fileIcon.selected、pogget.fileIcon.hovered布尔；是否选中、是否悬停
pogget.fileIcon.dimmed布尔；当前项目是否应淡化
pogget.fileIcon.hover数值；原生悬停动画进度
pogget.fileIcon.alpha、pogget.fileIcon.globalAlpha数值；项目不透明度与全局不透明度输入
pogget.fileIcon.previewMode数值；原生预览分类，供标准预设选择对应布局
pogget.fileIcon.ghost布尔；当前调用是否绘制拖动虚影
pogget.fileIcon.network布尔；是否为网络文本等网络项目

Markdown 编辑器 pogget.markdownEditor ​

这些输入在布局与相应绘制请求时更新。正文通过命名内容资源绘制；这些接口不开放脚本或 Markdown 语义内部样式。

pogget.markdownEditor.layoutZoom数值；布局使用的缩放值
pogget.markdownEditor.layoutScale数值；布局采用的实际倍率
pogget.markdownEditor.scale数值；本次内容绘制的实际倍率
pogget.markdownEditor.drawX、pogget.markdownEditor.drawY数值；内容实际绘制原点
pogget.markdownEditor.masterAlpha数值；本次绘制的整体不透明度
pogget.markdownEditor.textWidth、pogget.markdownEditor.textHeight数值；正文真实测量尺寸
pogget.markdownEditor.nativeMargin、pogget.markdownEditor.nativeTextSize数值；原生默认边距与字号
pogget.markdownEditor.wrap布尔；是否换行
pogget.markdownEditor.nativeRadius、pogget.markdownEditor.nativeBorder数值；原生圆角与边框宽度
pogget.markdownEditor.nativeBgAlpha、pogget.markdownEditor.nativeBorderAlpha数值；原生背景、边框不透明度
pogget.markdownEditor.background、pogget.markdownEditor.textColor、pogget.markdownEditor.borderColor颜色；当前有效背景、文字、边框色
pogget.markdownEditor.scrollX、pogget.markdownEditor.scrollY数值；横纵滚动偏移
pogget.markdownEditor.caretX、pogget.markdownEditor.caretY、pogget.markdownEditor.caretHeight数值；真实光标位置与高度
pogget.markdownEditor.caretOpacity数值；光标不透明度
pogget.markdownEditor.selectionX、pogget.markdownEditor.selectionY、pogget.markdownEditor.selectionWidth、pogget.markdownEditor.selectionHeight数值；本次选区片段矩形，来自真实字形测量
pogget.markdownEditor.placeholder文本；占位文字
pogget.markdownEditor.hintOpacity数值；缩放提示不透明度
pogget.markdownEditor.staticText布尔；是否以静态文本模式显示
pogget.markdownEditor.editing布尔；是否正在编辑
pogget.markdownEditor.selected布尔；是否有选区
pogget.markdownEditor.hasLayout布尔；正文布局是否可用
pogget.markdownEditor.verticalHover、pogget.markdownEditor.horizontalHover布尔；竖向/横向滚动条是否悬停
pogget.markdownEditor.verticalDrag、pogget.markdownEditor.horizontalDrag布尔；竖向/横向滚动条是否拖动
pogget.markdownEditor.zoomEnabled布尔；是否启用缩放

自定义视口请以 zoom 为独立输入。scale、drawX、drawY、layoutScale 是已经计算后的输出事实，不能反向用来定义自身视口，否则会形成布局反馈。

pogget.containerFrame.nativeRadius数值；原生窗口圆角
pogget.containerFrame.background颜色；窗口有效背景色
pogget.containerFrame.borderColor颜色；窗口有效边框色
pogget.containerFrame.borderOpacity数值；边框不透明度
pogget.containerFrame.customBorder布尔；是否启用自定义边框色
pogget.containerFrame.pointerX、pogget.containerFrame.pointerY数值；原生追踪的指针位置，用于光效
